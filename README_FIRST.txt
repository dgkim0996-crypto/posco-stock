[포스코증권 실행 방법]

1. 이 압축파일을 원하는 폴더에 풉니다.
2. package.json 파일이 보이는 폴더에서 터미널을 엽니다.
3. npm install
4. npm run dev

Windows에서는 START_POSCO.bat 더블클릭으로도 실행할 수 있습니다.

[MY 투자 화면 크기 변경]
1. 트레이딩 화면 아래의 '내 화면 편집' 클릭
2. ⠿ 를 잡고 드래그 = 창 순서 이동
3. 카드 오른쪽 아래 대각선 손잡이를 잡고 드래그 = 창 가로/세로 크기 변경
4. '편집 완료' 클릭
5. 배치는 자동 저장됩니다.
